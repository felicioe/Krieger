# Importação de PDF — regras

- The PDF divergence lock lives in `useTravaImportacao` (components/importacao): its baseline is only the demonstrativo applied from a PDF in this session or a record just created from a PDF (in-memory `criadoPorPdf`, never inferred from stored data), it is compared with the domain's `divergenciasImportacao`, and it is cleared only after a successful save, so later legitimate edits are never flagged.
- The PDF self-check (`ConferenciaPdf` in ResumoImportacao) only presents the domain's `resumoConferencia` state and coverage; it never claims the totals match unless the domain says `verificado`.
- Imports that create a new record start only from the `/importador` hub (one card per report type, `ImportarPdf modo="novo"` with its own `rotulo`); list screens just link to the hub, and `modo="editor"` stays inside open records, so there is a single entry point without losing in-record re-import.
- The Comparativo Financeiro is never a demonstrativo: the hub's `AnexarComparativo` accepts only `layout === "comparativo"`, attaches it to an existing exercício via the domain's `novoAnexoImportado` (PDF kept as `arquivoDataUrl` for download) in store `anexos_importacao`, and the prestação screen lists them in `AnexosPrestacao` outside the form, so download/delete never dirties or submits the exercício.
