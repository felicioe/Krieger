# Domain rules (src/domain)

- A new ata is built only by `novaAtaDeAssembleia`/`ataEmBranco` in `src/domain/ata.ts`; a finalized ata is locked by disabling the whole form `<fieldset>`, so new fields are locked automatically.
- Which edital fields a modalidade shows, and the cleanup of hidden fields on save, come only from `camposDaModalidade`/`prepararAssembleia` in `src/domain/edital.ts`, so the form and the saved data never disagree.
- A monthly report's month (competência) is derived from its demonstrativo period by `competenciaMensal` in `src/domain/mensal.ts`, because the `Mensal` type has no month field and field names cannot change.
- The live budget forecast is computed only by `calcularPrevisao` in `src/domain/previsao.ts` (used by the list and the editor); UI never recomputes totals on its own.
- The final report is assembled only by `montarRelatorioFinal` in `src/domain/relatorioFinal.ts` (sections, totals check, which monthly reports count); section choices live in `Exercicio.relatorioFinal` except "Análise gráfica", which reuses `mostrarAnalise`/`mostrarPizza`, so existing data keeps its meaning.
- Previsto × Realizado is computed only by `compararPrevistoRealizado` in `src/domain/previstoRealizado.ts`, which reuses `calcularPrevisao` (forced to item level) so the compared forecast always matches the editor; its pending business interpretations are listed in that file's header so they can change without schema changes.
- Systemar PDF import: `src/domain/pdfParser.ts` is the user's port of the production parser (change its logic only on request; type-only fixes allowed); the browser text extraction is `src/lib/pdfTexto.ts` (pdf.js, loaded lazily) + `src/domain/layoutTexto.ts` (pure layout rebuild); conversion to `Demonstrativo`, condo matching, the `importacoes` staging record and applying the optional "Considerações finais"/"Previsão sugerida" pages (`aplicarConsideracoesAoExercicio`, only for prestação de contas) come only from `src/domain/importacao.ts`, whose header lists the agent's pending interpretations.
- Edital block conditions and `{{campo.caminho}}` variables come only from the user's `src/domain/modeloTexto.ts` (`montarBlocos`); the edital document just draws its output by block type.
